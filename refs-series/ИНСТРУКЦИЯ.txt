─────────────────────────────────────────────
1. КАК ОТКРЫТЬ САЙТ У СЕБЯ
─────────────────────────────────────────────

Найдите в этой папке файл:

    Смотреть сайт.cmd

Щёлкните по нему дважды.

Что произойдёт:
  • откроется чёрное окно (это «сервер» — он раздаёт сайт);
  • сам откроется браузер с сайтом.

ВАЖНО: чёрное окно закрывать нельзя, пока вы смотрите сайт.
Когда закончили — просто закройте его.


─────────────────────────────────────────────
2. КАК РЕДАКТИРОВАТЬ
─────────────────────────────────────────────

Найдите в этой папке файл:

    Редактировать сайт.cmd

Щёлкните по нему дважды. Откроется админка.

Как добавить сериал и серию:
  • слева кнопка «+ сериал» — создать сериал;
  • в сериале кнопка «+ Серия» — создать серию;
  • впишите название и вставьте ссылку на видео.

Как поставить пояснение (отсылку):
  • в блоке «Превью и отсылки» включите видео;
  • остановите на нужном моменте;
  • нажмите «+ Отсылка на этой секунде»;
  • заполните заголовок и текст;
  • внизу «+ Ссылка» — добавьте, что посмотреть или прочитать.

Как добавить видео со своего диска (файл Bandicam, запись экрана и т.п.):
  • создайте серию и выберите «Источник» → «Файл / прямой URL»;
  • нажмите «Выбрать видео на диске» и укажите ваш .mp4
    (или просто перетащите файл из проводника в пунктирную рамку);
  • подождите, пока полоска дойдёт до конца, — файл скопируется
    в папку videos внутри сайта;
  • видео тут же появится в превью ниже.

  ВАЖНО: вставлять путь вида C:\Users\... в текстовое поле бесполезно —
  браузер не открывает файлы по таким путям. Всегда используйте
  кнопку «Выбрать видео на диске».

Если из длинной записи нужен только кусок:
  • в блоке «Отрезок из файла» включите видео выше;
  • остановите на нужном моменте и нажмите
    «Начало = текущая секунда»;
  • промотайте дальше и нажмите «Конец = текущая секунда»;
  • готово: сайт будет показывать только этот кусок,
    а таймкоды отсылок начнутся с 0:00 (от его начала).
  Сам файл не перекодируется и не портится.

Как добавить видео с другого сайта (griffinfan.ru, VK, Rutube и подобные):
  • создайте серию и выберите «Источник» → «Любой другой сайт»;
  • на сайте с видео нажмите «Поделиться» → «Встроить» и скопируйте
    код (он начинается с <iframe src="...">);
  • вставьте этот код в большое поле в админке;
  • ниже сразу появится превью — видно, работает ли вставка.

  Если кода нет, можно вставить просто адрес страницы с видео.
  Если превью пустое — сайт запрещает показ своих страниц у других;
  попробуйте найти у него ссылку «плеер»/«embed» и вставить её.

Как вставить готовые субтитры:
  • кнопка «Импорт .srt» → выберите файл субтитров;
  • каждый блок станет отсылкой, дальше правьте текст вручную.

Где всё хранится:
  • правки сами сохраняются в браузере (это «черновик»);
  • кнопка «Скачать data.json» — сохранить файл на компьютер.

  Пока вы не подключили GitHub (пункт 3), изменения видны
  только в этом браузере на этом компьютере.


─────────────────────────────────────────────
3. КАК ОПУБЛИКОВАТЬ В ИНТЕРНЕТЕ (бесплатно)
─────────────────────────────────────────────

Нужен аккаунт на github.com — это бесплатно и без карты.
Сайт будет жить по адресу вида:
    https://ваш-логин.github.io/refs-series/

Шаг 1. Зарегистрируйтесь на github.com (если ещё нет).

Шаг 2. Создайте репозиторий:
  • нажмите зелёную кнопку «New» (или «+» справа сверху → New repository);
  • Repository name: refs-series
  • выберите Public;
  • «Create repository».

Шаг 3. Загрузите файлы:
  • на странице пустого репозитория нажмите
    «uploading an existing file»;
  • откройте папку refs-series на компьютере;
  • выделите ВСЁ содержимое папки (Ctrl+A) и перетащите
    в окно браузера;
  • внизу нажмите зелёную «Commit changes».
  • Проверьте, что внутри появились: index.html, admin.html,
    папки css, js, data.

Шаг 4. Включите сайт:
  • в репозитории: Settings (сверху) → Pages (слева);
  • Source: «Deploy from a branch»;
  • Branch: main, папка / (root) → Save;
  • через минуту-две сайт откроется по адресу из этой же страницы.

Шаг 5. Разрешите редактирование (токен):
  • на github.com: нажмите на свою аватарку → Settings →
    внизу Developer settings → Personal access tokens →
    Fine-grained tokens → Generate new token;
  • Repository access: Only select repositories → refs-series;
  • Permissions → Contents: Read and write;
  • Generate token и скопируйте его (он показывается один раз!).

Шаг 6. Подключите админку:
  • откройте свою админку — адрес сайта + /admin.html,
    например https://ваш-логин.github.io/refs-series/admin.html
    (или локально через «Редактировать сайт.cmd»);
  • впишите: логин, refs-series, main, data/data.json и токен;
  • «Подключиться».

Теперь кнопка «Опубликовать» отправляет правки на сайт.
Обновление занимает около минуты.


─────────────────────────────────────────────
ЧТО ВАЖНО ЗНАТЬ
─────────────────────────────────────────────

• Видео лучше держать на YouTube («доступно по ссылке»).
  Бесплатный хостинг не хранит большие файлы.
• Свои mp4 до 95 МБ можно загрузить прямо из админки.
• Rutube и VK: сайт не может показывать всплывающие пояснения —
  у них нет нужного для этого интерфейса. Список отсылок работает.
• Токен — это ключ от вашего репозитория. Не вставляйте его
  на чужом компьютере. Кнопка «Забыть токен» удаляет его.
• Если сайт не открылся: закройте чёрное окно, запустите .cmd снова.
  Если пишет про порт — значит, окно уже открыто, закройте старое.
