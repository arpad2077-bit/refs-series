# Отсылки — сериалы с пояснениями

Статический сайт: под каждой серией видео плеер, поверх видео всплывают пояснения отсылок, под плеером — список отсылок с таймкодами и ссылками «что посмотреть / прочитать».

Ни сборки, ни зависимостей, ни сервера: `index.html` + `admin.html` + `data/data.json`.

## Что умеет

- **Каталог сериалов** → серии → просмотр.
- **Всплывающие пояснения** поверх видео в заданные моменты (форсированные субтитры).
- **Список отсылок** с таймкодом, текстом и ссылками. Клик по таймкоду перематывает.
- **Плеер**: play/pause, перемотка, время, громкость (запоминается в браузере), звук вкл/выкл, на весь экран, «следующая серия». Горячие клавиши: `пробел`, `←`/`→` (±5 с), `f`, `m`, `[` / `]` — предыдущая/следующая отсылка.
- **Автопереход** к следующей серии по окончании (можно отключить).
- **Админка**: загрузка видео, редактор отсылок по таймкоду, ссылки, импорт `.srt`, публикация в GitHub.

### Какие видео поддерживаются

| Источник | Пояснения поверх видео | Громкость из сайта |
|---|---|---|
| YouTube | да | да |
| mp4 / webm (в репозитории или по ссылке) | да | да |
| Rutube, VK, прочие iframe | нет | нет |

Для Rutube и VK нет документированного API плеера: сайт не видит текущий таймкод. Такие серии показывают список отсылок, а клик по таймкоду открывает видео с нужным временем (если хостинг это поддерживает). Если нужны сами всплывающие пояснения — используйте YouTube (можно «доступно по ссылке») или свой файл.

## Локальный запуск

Node и Python не нужны — есть маленький сервер на PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Откройте <http://localhost:8080/> (сайт) и <http://localhost:8080/admin.html> (редактор).

Можно и просто открыть `index.html` двойным щелчком: тогда покажется демо-контент из `js/data.js`, а админка будет работать в локальном режиме без публикации.

Порт занят — `-Port 8090`.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий, например `refs-series`.
2. Загрузите в него файлы проекта (на github.com можно перетащить папку).
3. `Settings → Pages → Source: Deploy from a branch`, ветка `main`, папка `/ (root)`. Сайт будет на `https://<логин>.github.io/<репозиторий>/`.
4. Создайте токен: `Settings → Developer settings → Personal access tokens → Fine-grained tokens`. Доступ — только к этому репозиторию, права `Contents: Read and write`.
5. Откройте `admin.html` на своём сайте (или локально), введите логин, имя репозитория, ветку и токен.

Токен хранится только в `localStorage` вашего браузера — это инструмент для одного редактора, а не многопользовательская авторизация. Не вводите токен на чужом компьютере; кнопка «Забыть токен» удаляет его.

## Как пользоваться админкой

1. **Сохранение.** Все правки сразу попадают в черновик браузера. «Сохранить черновик» — явная точка сохранения, «Опубликовать» — коммит `data/data.json` в репозиторий. GitHub Pages обновится в течение минуты.
2. **Видео.** Тип: YouTube (вставьте любую ссылку — id распознается), файл (путь `videos/x.mp4` или прямой URL) или чужой iframe. Для файла до 95 МБ есть кнопка загрузки в репозиторий; больше — загружайте на YouTube/archive.org и вставляйте ссылку.
3. **Отсылки.** Поставьте превью на нужный момент → «+ Отсылка на этой секунде» → заголовок, текст, длительность показа, спойлер, ссылки.
4. **Импорт `.srt`.** Каждый блок субтитров станет отсылкой с тем же таймкодом — удобно, когда пояснения уже надиктованы или переведены.

## Формат данных

`data/data.json`:

```json
{
  "site": { "title": "Отсылки", "subtitle": "..." },
  "series": [{
    "id": "demo",
    "title": "Название сериала",
    "poster": "https://...",
    "description": "...",
    "episodes": [{
      "id": "demo-1",
      "number": 1,
      "title": "Серия 1",
      "description": "...",
      "video": { "kind": "youtube", "ref": "aqz-KE-bpKQ" },
      "notes": [{
        "id": "n1",
        "t": 83.5,
        "dur": 6,
        "title": "Заголовок",
        "text": "Пояснение отсылки",
        "spoiler": false,
        "links": [
          { "kind": "watch", "label": "Первоисточник", "url": "https://..." }
        ]
      }],
      "nextOverride": null
    }]
  }]
}
```

- `video.kind`: `youtube` | `file` | `embed`.
- `t` — секунды, можно дробные. `dur` — сколько секунд держать пояснение на экране.
- `links[].kind`: `watch` | `read` | `listen`.
- `nextOverride` — id серии, которая должна открываться следующей вместо следующей по порядку.

## Ограничения

- Бесплатный хостинг не хранит видео: большие серии живут на YouTube/archive.org. В репозиторий имеет смысл класть только небольшие ролики (GitHub: 100 МБ на файл, около 1 ГБ на репозиторий).
- Для Rutube/VK синхронные пояснения невозможны — это ограничение их плееров.
- Правки в админке — только через браузер с токеном; файл `data/data.json` можно править и вручную на github.com.
